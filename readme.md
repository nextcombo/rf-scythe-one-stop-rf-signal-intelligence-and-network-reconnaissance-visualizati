# RF SCYTHE: One-stop RF Signal Intelligence and Network Reconnaissance Visualization Platform [with code]

RF SCYTHE: A one-stop RF Signal Intelligence and Network Reconnaissance Visualization Platform. In the field of RF Signal Intelligence Analysis and Network Reconnaissance, fragmented tools, disjointed collaboration methods, and abstract data analysis have always been industry pain points. Today, we are introducing the RF SCYTHE, a full-stack visualization platform that directly addresses these pain points. It integrates real-time signal analysis, 3D geographic visualization, and multi-device collaboration capabilities, making complex RF signals and network reconnaissance tasks more intuitive and efficient.
Core Value: From "Data Fragments" to "Panoramic Insights" - RFSCYTHE is specifically designed for the Linux environment (tested on Alma Linux 9 / WSL2), with a core goal of breaking down information barriers across various stages of RF signal intelligence and network reconnaissance. Whether it involves parsing signal data, linking geographical dimensions, or collaborative analysis among team members, all can be completed within this platform, eliminating the need to switch between multiple tools, significantly enhancing analytical efficiency.
These core capabilities, reconstructing the experience of reconnaissance analysis. 1. Real-time data parsing + geographic positioning, allowing data to "land" on the platform. Support for real-time parsing of PCAP data, combined with MaxMind GeoLite2 geolocation technology, can quickly associate abstract network packets with specific geographical locations, making every signal and every network interaction have clear spatial coordinates, moving away from the purely numerical data analysis model.
2.3D Earth Visualization, a clear overview of the global situation. Relying on the Cesium 3D Earth engine, the platform can intuitively display information such as physical marker marks, network flow trajectories, satellite orbits, and AIS ship dynamics. Whether it is the localization of single targets or the distribution of large-scale signal situations, they can be clearly displayed in three-dimensional space, making situation perception more three-dimensional.
3. Intelligent Tracking + Automated Surveillance, Reducing Manual Costs The built-in SuperMap engine employs a memory-level graphics architecture, combined with spatial indexing and event bus technology, to achieve precise tracking of entities. The automated reconnaissance function can automatically discover target entities and track their status, reducing the workload of manual inspections by analysts.
4. Collaborative Space for Multi-Operators, Real-Time Synchronized Analysis Results Support for Multi-Operational Room Functionality. Based on SSE/WebSocket technology, real-time synchronization of analysis data and operational instructions is achieved. Coupled with SQLite data persistence capabilities, even in multi-end collaboration, data consistency can be ensured. Team members can share the same situational view to efficiently collaborate on reconnaissance tasks.
5. Dual-Layer Detection Strategy, Ensuring Accurate Judgment. The platform's built-in detection registration mechanism adopts a "real-time edge detection + persistent aggregate detection" dual-layer strategy, which not only captures real-time anomalies and network behavior but also avoids misjudgments through aggregate analysis, ensuring more reliable reconnaissance results.
Three Steps to Start: Quick Start Platform. No complex configuration required; simply three steps to start using the platform:
1  
Install basic dependencies: Complete the deployment of Python-related dependency packages to meet the core environment requirements for the platform's operation;
2  
Start the server: A single click to initiate the core services will enable the platform's various capabilities;
3  
Open the console: Access the visualization interface through a browser, starting the analysis work.
Lightweight Architecture, Stability and Easy to Expand. RF SCYTHE's architecture design balances stability and scalability:
★  
Frontend visualization layer: Centered around a 3D Earth interface, integrating entity visualization, coordinate verification, and anomaly handling capabilities, making the interface intuitive and user-friendly;
★  
API service layer: As the core hub, it accepts frontend interaction requests and provides comprehensive interfaces for reconnaissance entity management, PCAP data processing, supermap query, and collaborative room management;
★  
Core engine layer: Including the SuperMap engine and write bus as core components, the write bus acting as the sole entry point for data changes ensures the consistency of all platform data;
★  
Data management layer: Covering PCAP, detection, reconnaissance, and other types of registrars, paired with an automatically created SQLite database, achieving standardized data storage and management.
Furthermore, the platform supports custom configuration of environment variables, allowing for adjustments to database paths, Redis connections, and Cesium map tokens based on actual usage scenarios, catering to different deployment needs.
In summary, RF SCYTHE is not merely a tool stack; it is an integrated solution that starts from the entire process of RF signal intelligence and network reconnaissance. It integrates real-time analysis, 3D visualization, multi-user collaboration, and intelligent detection capabilities deeply, making complex and scattered reconnaissance tasks efficient and intuitive. Whether it's small-scale judgment by individual soldiers or large-scale situational analysis by teams, this platform can enhance work efficiency and facilitate the rapid transformation from data to insights.
